# 이미지 서랍 · ImgBB 업로더 1.0.1

내 PC의 이미지를 ImgBB에 업로드하고 공유 링크·즐겨찾기·업로드 이력을 관리하는 한글 로컬 웹 앱입니다. ImgBB 공식 앱이 아닌 독립 도구이며, 각 사용자가 본인의 ImgBB API 키를 발급받아 사용합니다.

## 시작하기

1. https://nodejs.org/ko 에서 Node.js 22 이상을 설치합니다.
2. ZIP을 원하는 폴더에 **모두 압축 해제**합니다. ZIP 안에서 실행하지 마세요.
3. Windows는 `실행.cmd`를 더블클릭합니다. 실행 환경을 검사하고 서버와 브라우저를 엽니다. 터미널은 앱을 사용하는 동안 유지하고, 종료할 때 Ctrl+C를 누릅니다.
4. 브라우저가 안 열리면 http://127.0.0.1:3210 으로 접속합니다.
5. `API 키 설정 필요` → https://api.imgbb.com/ 에서 본인 키 발급 → 입력 → `설정 저장`을 누릅니다.
6. 이미지 선택·끌어놓기·클립보드 붙여넣기 후 `대기 항목 업로드`를 누릅니다.

macOS·Linux 또는 명령행에서는 `npm start`로 실행하고 위 주소를 직접 여세요. PowerShell에서 npm 실행이 차단되면 `npm.cmd start`를 사용합니다. 추가 패키지를 설치할 필요는 없습니다. Windows에서 검증했으며 다른 OS의 화면 동작은 별도 실기 검증하지 않았습니다.

포트가 사용 중이면 PowerShell에서 `$env:PORT=3212; npm.cmd start`로 실행합니다. 포트가 바뀌면 브라우저 저장소도 별개이므로 기존 이력을 백업한 뒤 가져오세요. 실행기를 검사만 하려면 `실행.cmd --check`를 사용합니다.

## 제공 기능

- 이미지당 최대 32MB, 여러 이미지 순차 업로드와 미리보기
- 자동 삭제 기간 선택(사용 안 함·10분·1시간·1일·7일·30일·180일)
- 이름 검색·정렬·즐겨찾기·여러 이미지 링크 복사
- 원본 URL·공유 페이지·마크다운·HTML·게시판 코드 복사
- 업로드 이력 JSON 백업·가져오기, ImgBB 삭제 페이지 연결

JPG·PNG·GIF·WEBP·BMP·TIFF·AVIF·HEIC·HEIF 선택을 지원하며 실제 수용 여부는 ImgBB 정책에 따릅니다. 이 앱에서 업로드하거나 백업으로 가져온 이력만 보입니다. 계정 전체 이미지·앨범 동기화 기능은 없습니다.

## 재시도와 데이터 보관

- 시간 초과·통신 단절·응답 해석 실패는 **결과 확인 필요**로 남깁니다. 새 파일을 업로드해도 이 항목을 함께 전송하지 않습니다. ImgBB에서 미업로드를 확인한 뒤 해당 항목의 `확인 후 재시도`를 눌러 예약하고 업로드하세요.
- 명확하게 실패한 항목도 `재시도 예약`으로 직접 선택해야 합니다. 자동 재시도는 없습니다.
- 대기열과 파일은 메모리에만 있습니다. 창을 닫거나 새로고침하면 사라지며, 전송 중이거나 결과 불명 항목이 있으면 브라우저의 닫기 경고를 요청합니다. 창을 다시 연 뒤에는 이전 전송 상태를 복구할 수 없으므로 ImgBB에서 먼저 확인하세요.
- 이미지와 API 키는 업로드 시 내 PC의 로컬 서버를 거쳐 **ImgBB**로 전송됩니다. 로컬 서버는 원본과 키를 디스크에 저장하지 않습니다. 서버는 127.0.0.1에만 열리며 공유 호스팅용 서버가 아닙니다.
- 업로드 이미지는 공개 링크로 접근할 수 있습니다. 개인정보·비공개 자료를 업로드하기 전에 공개 여부를 확인하세요.
- API 키는 기본적으로 탭의 세션 저장소에 보관됩니다. `이 브라우저에 API 키 기억하기`를 선택하면 브라우저 저장소에 **평문**으로 저장됩니다. 공용 PC에서는 사용하지 마세요. `저장된 키 지우기`로 삭제할 수 있습니다.
- 이력은 현재 브라우저·포트의 로컬 저장소에 보관됩니다. 다른 브라우저로 자동 이동하지 않습니다. 저장 공간 부족 시 백업을 내보내세요.
- 백업에 API 키·원본 파일은 없지만 **이미지 삭제 링크는 포함**됩니다. 백업을 공개 저장소에 올리지 마세요.
- `이력에서 삭제`는 ImgBB 이미지를 삭제하지 않습니다. 실제 삭제는 `ImgBB 삭제 페이지`에서 진행합니다.

## 테스트·소스

`npm.cmd test` 또는 `node --test`로 검증합니다. 테스트에는 모의 응답과 테스트용 값만 쓰며 실제 이미지나 키를 ImgBB에 전송하지 않습니다. 워드프레스나 별도 개인 프로젝트는 필요하지 않습니다.

구성: `server.mjs`(로컬 중계), `launcher.cjs`(버전 검사), `public/`(한글 UI·재시도 정책), `test/`(독립 테스트). 사용자 키·백업·개인 워드프레스 설정은 동봉하지 않습니다.
