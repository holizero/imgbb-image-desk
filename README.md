# 이미지 서랍 · ImgBB 업로더

내 PC의 이미지를 ImgBB에 업로드하고 링크·즐겨찾기·이력을 관리하는 한글 앱입니다.

**앱 소개, 설치 방법, 워드프레스 활용법과 주의사항은 [블로그 포스팅](https://mntkim.com/wordpress-imgbb-image-desk-free-image-hosting/)에서 확인하세요.**

[English guide](https://mntkim.com/en/wordpress-imgbb-image-desk-free-image-hosting/)

- [v1.0.1 배포 ZIP 다운로드](https://github.com/holizero/imgbb-image-desk/releases/download/v1.0.1/image-desk-v1.0.1.zip)
- [릴리스 및 체크섬 파일](https://github.com/holizero/imgbb-image-desk/releases/tag/v1.0.1)

Node.js 22 이상과 본인의 ImgBB API 키가 필요합니다. MIT 라이선스이며 ImgBB 공식 앱은 아닙니다.
